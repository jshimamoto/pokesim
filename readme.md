# PokeSim

Barebones Pokemon battle simulator to explore an OOP approach

# Plan
Each turn creates a new instance of an `ITurn`. This class will take all of the information of the opponents and execute all necessary steps in order
- Core events
  - Who goes first
  - Ability triggers
  - Item triggers
  - Attack damage
  - Status conditions
- Future extensions
  - Weather effects
  - Priority moves
